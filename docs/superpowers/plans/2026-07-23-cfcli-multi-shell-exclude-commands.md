# cfcli multi-shell exclusion commands implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the OS-selected quick exclusion command with labeled POSIX, PowerShell, and `cmd.exe` variants.

**Architecture:** Serialize each finding once and return a fixed-order slice of labeled shell commands. Keep separate
pure quoting helpers for POSIX, PowerShell, and Windows argv syntax, then let quick mode emit every returned command.

**Tech Stack:** Go 1.21, standard-library JSON/path/string packages, Go `testing`

## Global constraints

- Always emit POSIX, PowerShell, and `cmd.exe` commands in that order.
- Prefix every command line with `TEXT: <Shell>: `.
- Use one absolute root and one serialized finding for all commands.
- Do not inspect `runtime.GOOS` or the parent process.
- Preserve quick-mode termination, summaries, and exit codes.
- Keep JSON mode free of exclusion commands.
- Preserve unrelated worktree changes.

- [ ] **Step 3: Implement the command model and quoting helpers**

Replace `quoteShellArgument` and `formatExcludeCommand` with:

```go
type shellCommand struct {
	Label   string
	Command string
}

func quotePOSIXArgument(value string) string {
	return "'" + strings.ReplaceAll(value, "'", "'\"'\"'") + "'"
}

func quotePowerShellArgument(value string) string {
	return "'" + strings.ReplaceAll(value, "'", "''") + "'"
}

func quoteCmdArgument(value string) string {
	var quoted strings.Builder
	quoted.WriteByte('"')
	backslashes := 0
	for _, current := range value {
		if current == '\\' {
			backslashes++
			continue
		}
		if current == '"' {
			quoted.WriteString(strings.Repeat("\\", backslashes*2+1))
			quoted.WriteRune('"')
			backslashes = 0
			continue
		}
		quoted.WriteString(strings.Repeat("\\", backslashes))
		backslashes = 0
		quoted.WriteRune(current)
	}
	quoted.WriteString(strings.Repeat("\\", backslashes*2))
	quoted.WriteByte('"')
	return quoted.String()
}
```

Serialize the event once and construct the three commands:

```go
func formatExcludeCommands(root string, event finding) ([]shellCommand, error) {
	absoluteRoot, err := filepath.Abs(root)
	if err != nil {
		return nil, fmt.Errorf("resolve repository path: %w", err)
	}
	encoded, err := json.Marshal(event)
	if err != nil {
		return nil, fmt.Errorf("encode finding: %w", err)
	}
	rootArgument := filepath.Clean(absoluteRoot)
	eventArgument := "JSON: " + string(encoded)
	return []shellCommand{
		{Label: "POSIX", Command: "cfcli exclude " + quotePOSIXArgument(rootArgument) + " " +
			quotePOSIXArgument(eventArgument)},
		{Label: "PowerShell", Command: "cfcli exclude " + quotePowerShellArgument(rootArgument) + " " +
			quotePowerShellArgument(eventArgument)},
		{Label: "cmd.exe", Command: "cfcli exclude " + quoteCmdArgument(rootArgument) + " " +
			quoteCmdArgument(eventArgument)},
	}, nil
}
```
